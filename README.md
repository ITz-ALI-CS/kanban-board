## ✨ Features
- Drag and drop cards between 4 columns: To Do, In Progress, Review, Done
- Priorities, labels and due dates, with overdue highlight
- Search and priority filter
- Live stats and animated progress bar
- Confetti when you finish a task
- Double-click to edit, Undo after delete
- Dark and light theme with 4 accent colors
- Export and Import tasks as a JSON file
- Tasks are saved in your browser
- Shortcuts: `N` new task, `/` search
